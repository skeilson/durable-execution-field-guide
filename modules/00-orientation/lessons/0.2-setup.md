# 0.2 Set up your machine

**Time:** 20–30 minutes

You don't need to be a programmer to run this course. You need three things installed and the ability to paste commands into a terminal.

## 1. Install the tools

| Tool | Why | Get it |
| --- | --- | --- |
| **Node.js 20 or newer** | Runs the labs | [nodejs.org](https://nodejs.org) (choose "LTS") |
| **Git** | Downloads the project | [git-scm.com](https://git-scm.com/downloads) (already on most Macs) |
| **A terminal** | Where you type commands | macOS: *Terminal* app. Windows: see the note below. |

> **Windows:** the Restate server runs on macOS and Linux. On Windows, install [WSL](https://learn.microsoft.com/windows/wsl/install) (Windows Subsystem for Linux), open the *Ubuntu* app it adds, and do everything below inside it.

Check that it worked:

```bash
node --version    # should print v20 or higher
git --version
```

## 2. Download the project

```bash
git clone https://github.com/skeilson/durable-execution-field-guide.git
cd durable-execution-field-guide
npm install
```

`npm install` downloads everything else, including the Restate server and CLI. Nothing is installed system-wide.

## 3. Check that everything works

```bash
npm run m1
```

You should see a checkout program run, crash, and charge a customer twice. That's supposed to happen: it's the first lesson of Module 1. If you see it, you're set up.

## 4. Optional: an editor for reading code

You can read all the code on GitHub, but a code editor makes it easier: colors, a file tree, and a built-in terminal. [Visual Studio Code](https://code.visualstudio.com) is free and the most common choice. Open the project folder with *File → Open Folder*.

## If something goes wrong

| Message | Fix |
| --- | --- |
| `address already in use` / port 8080, 9070 or 9080 | Something else is using that port. Stop other demos (`Ctrl+C`), or restart your computer. |
| `command not found: npm` | Node.js isn't installed or the terminal was opened before installing. Open a new terminal. |
| Lesson stops partway with a timeout | Run `npm run reset`, then try again. |

To clear all local demo data at any time: `npm run reset`.
