# 5.2 The same app, built twice

**Time:** 30 minutes

Open the two checkouts side by side: [Restate `orders.ts`](../../03-restate/shop/orders.ts) and [Temporal `workflows.ts`](../../04-temporal/shop/workflows.ts) with [`activities.ts`](../../04-temporal/shop/activities.ts).

## Checkout

**Restate**

```ts
checkout: async (ctx: restate.Context, order: Order) => {
  const reservation = await ctx.run("reserve inventory", () => inventory.reserve(order.orderId, order.sku));
  const payment = await ctx.serviceClient(payments).charge({ orderId: order.orderId, amountCents: order.amountCents });
  ctx.serviceSendClient(emails).send({ orderId: order.orderId, subject: "Thanks for your order" });
  await ctx.sleep({ seconds: PICKUP_WAIT }, "wait for warehouse pickup");
  const tracking = await ctx.run("ship order", () => shipping.ship(order.orderId, order.address));
  return { orderId: order.orderId, reservation, payment, tracking };
}
```

**Temporal**

```ts
export async function checkout(order: Order) {
  const reservation = await acts.reserveInventory(order.orderId, order.sku);
  const payment = await acts.chargeCard(order.orderId, order.amountCents);
  await acts.sendEmail(order.orderId, "Thanks for your order");
  await sleep(`${order.pickupSeconds ?? 5} seconds`);
  const tracking = await acts.shipOrder(order.orderId, order.address);
  return { orderId: order.orderId, reservation, payment, tracking };
}
```

## What differs, line by line

| | Restate | Temporal |
| --- | --- | --- |
| Side effects | Inline `ctx.run` closures | Separate activity functions, called by name |
| Calling payments | Another **service** (its own invocation, journal and retries) | An **activity** in the same worker |
| Fire-and-forget email | `serviceSendClient` (durable, caller doesn't wait) | Awaited activity (or a child workflow with an "abandon" parent close policy) |
| Wait | `ctx.sleep` | `sleep` |
| Configuration | Timeouts and retries on the service/handler, sensible defaults | `startToCloseTimeout` required on every activity proxy |
| Where it runs | One HTTP service process | One worker (workflow code sandboxed, activities not) |

## The rest of the shop

| Feature | Restate | Temporal |
| --- | --- | --- |
| Cart | Virtual object [`cart.ts`](../../03-restate/shop/cart.ts): built-in state, per-key queue | Entity workflow `cart`: signals, query, update, continue-as-new |
| Return approval | Workflow + durable promise [`returns.ts`](../../03-restate/shop/returns.ts) | Workflow + signal + query `returnRequest` |
| Webhook | Awakeable [`async-payments.ts`](../../03-restate/shop/async-payments.ts) | Signal from the webhook handler `asyncPayment` |
| Saga | [`order-saga.ts`](../../03-restate/shop/order-saga.ts) | `orderSaga` |
| Retry limit | `onMaxAttempts: "pause"` → paused | `maximumAttempts` → activity fails → workflow fails |
