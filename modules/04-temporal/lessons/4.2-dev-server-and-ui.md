# 4.2 Running the dev server and Web UI

**Time:** 20 minutes

## Install the Temporal CLI

Unlike Restate, the Temporal server doesn't come from `npm install`. Install the **Temporal CLI** once; it includes a full development server.

| Your machine | Install |
| --- | --- |
| macOS | `brew install temporal` |
| Linux / WSL | `brew install temporal` if you use Homebrew; otherwise download the Linux archive from [temporal.download](https://temporal.download), extract it, and put `temporal` on your PATH |

Check it worked:

```bash
temporal --version
```

## Start the dev server

```bash
npm run temporal          # runs: temporal server start-dev
```

That gives you:

- the Temporal service on `localhost:7233`, where workers and clients connect
- the **Web UI** at **http://localhost:8233**
- a namespace called `default`

The dev server keeps everything **in memory**: stop it and every workflow is gone. That's fine for learning. (`--db-filename temporal.db` would persist to a file.) A production Temporal service is a cluster of services backed by a database such as PostgreSQL or Cassandra, or Temporal Cloud.

## Try the CLI

```bash
temporal operator namespace list
temporal workflow list
```

Both talk to `localhost:7233` by default.

## The Web UI

Open http://localhost:8233. You'll use it constantly in this module:

- **Workflows:** every execution, filterable by status and type
- **A workflow's page:** its input and result, pending activities, and the **event history** as a list, a compact view, or a timeline
- **Task queues:** linked from a workflow, showing which workers are polling

> **▶ Run it**
> ```bash
> npm run m4 -- 4.2
> ```
> The lesson scripts start their own dev server, so stop yours (Ctrl+C) first. Two servers can't share port 7233.

## Things that go wrong here

| Symptom | Cause |
| --- | --- |
| `command not found: temporal` | CLI not installed, or not on your PATH. Open a new terminal after installing. |
| `address already in use` on 7233 | Another dev server is running. |
| Workflows disappear | The dev server was restarted: its storage is in memory. |
