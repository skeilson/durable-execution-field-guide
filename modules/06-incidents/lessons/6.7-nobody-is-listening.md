# 6.7 Nobody is listening

**Time:** 20 minutes · **Run:** `npm run m6 -- 6.7` · **Builds on:** 3.2, 4.4

## The ticket

> **From:** Jordan Pike, Developer, Lumen Labs (trial account) · **Priority:** Normal
> **Subject:** Getting "service not found" — Restate is broken?
>
> Following the quickstart. My service is running (I can see "listening on 9080"), Restate is running, but every request returns an error saying the service isn't found. I've restarted everything twice.

A trial user, early in onboarding. How this ticket is handled may decide whether they become a customer.

## Investigation

```
→ HTTP 404 {"message":"service 'Orders' not found, make sure to register the service before calling it."}
```

```bash
npx restate deployments list
# No deployments were found! Did you forget to register your deployment with 'restate dep register'?
```

## Root cause

The service was never **registered**. Restate only routes to deployments it knows about. A service listening on a port isn't enough: Restate has to be told where it is (lesson 3.2).

## Resolution

```bash
npx restate deployments register http://localhost:9080
```

Variants of this ticket you'll see:

| Setup | Symptom | Fix |
| --- | --- | --- |
| Restate in Docker, service on the host | Registration fails: connection refused | Register `http://host.docker.internal:9080` (Docker Desktop), not `localhost` |
| Service redeployed at a new URL | Old URL registered, now unreachable | Register the new URL as a new deployment |
| Typo in the service name in the request | 404 for that name only | `restate services list` shows the real names |

## In Temporal: the silent version

Temporal's version of "nobody is listening" doesn't return an error at all. A worker polling `shop` and a client starting workflows on `Shop` (or in a different namespace) produce workflows that sit **Running** forever with a pending workflow task. `temporal task-queue describe --task-queue Shop` shows no pollers. The fix is aligning task queue and namespace names. These tickets often arrive as "Temporal is slow" or "Temporal is stuck."
